# Нет Терпения и Исчерпания

Сделки обрывались Исчерпанием после 2–3 Ходов: запас присутствия (`1 + Вежливость // 20`) был слишком коротким для настоящей торговли. Убираем Терпение и исход Исчерпание; мягкий стоп только Уход, бесконечный стол допустим. Вежливость остаётся чертой голоса на старте и на длину/Уход не влияет.

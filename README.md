# Переговоры с инвестором

Одна Сделка: Основатель торгуется с Инвестором. Решения принимает Jev (`jev-1.13`), речь пишет LLM (`openai/gpt-4o-mini`) через один ключ [RouterAI](https://routerai.ru/). Без ключа процесс не стартует.

## Требования

- Python **3.14** или новее (`python3 --version`)
- `pip` у этой же версии Python
- ключ RouterAI

Команды ниже выполняются из **корня репозитория** — того каталога, где лежат `pyproject.toml` и `.env`. Оттуда `load_dotenv()` находит ключ.

## 1. Окружение

```bash
cd /путь/к/invest-games
python3 --version          # должно быть 3.14.x
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -U pip
python -m pip install -e .
```

После установки в PATH появляются скрипты `invest-games` и `invest-games-web`. Если команда «не найдена», вы не в `.venv` либо ставили другим `python`.

Проверка импорта:

```bash
python -c "import invest_games; print('ok')"
```

## 2. Ключ

В корне репозитория создайте файл `.env` (он в `.gitignore`, в git не попадёт):

```env
TYPESAFE_API_KEY=ваш_ключ_routerai
TYPESAFE_BASE_URL=https://routerai.ru/api
```

Тот же ключ можно экспортировать в шелл:

```bash
export TYPESAFE_API_KEY=ваш_ключ_routerai
export TYPESAFE_BASE_URL=https://routerai.ru/api
```

Если ключа нет или он пустой, консоль и веб сразу выходят с текстом:

`Нужен ключ RouterAI (TYPESAFE_API_KEY). Без него стол не стартует.`

## 3. Консоль

Из корня репозитория, с активированным `.venv`:

```bash
invest-games
```

То же самое через модуль:

```bash
python -m invest_games.cli
```

Приложение спросит два числа и откроет стол:

```text
Жадность (0-100): 40
Вежливость (0-100): 60
```

Дальше приглашение `>` — ход строкой. `Ctrl+D` (на Windows `Ctrl+Z`) тоже выходит из цикла ввода. Сбой RouterAI печатает ошибку, стол не меняется, ту же строку можно повторить.

## 4. Веб

Из корня репозитория, с активированным `.venv`:

```bash
invest-games-web
```

То же самое:

```bash
python -m invest_games.web
```

Сервер слушает **http://127.0.0.1:8000**. Остановка — `Ctrl+C`.

На стартовой странице слайдеры Жадности и Вежливости (0–100), затем одно поле чата с тем же языком строк, что в консоли. Cookie держит текущую Сделку: обновление страницы не открывает новую, пока жив процесс. Другого браузера / инкогнито — другая cookie и новая партия в том же процессе.

Порт или хост можно сменить через uvicorn напрямую:

```bash
python -m uvicorn invest_games.web:create_app --factory --host 127.0.0.1 --port 8000
```

## Ходы за столом

Одно поле, консоль и веб одинаковые. Регистр не важен.

| Строка | Что происходит |
| --- | --- |
| любая фраза без команды | речь, оффера нет |
| `предложить 500_000 20` | Раунд: сумма и Доля |
| `предложить 500 000€ 20` | тот же Раунд |
| `предложить покупка 800000` | Покупка |
| `предложить купить 800 000` | та же Покупка |
| `уйти` или `quit` | Отказ Основателя, стол закрыт |
| `предложить` без чисел | ошибка ввода, ход в Jev не идёт |

Сумма: цифры, пробелы, `_`, `€`. Доля: целое от 1 до 99. Согласие на оффер Инвестора — обычной речью, кнопки «Принять» нет.

## Если не стартует

- `requires-python >=3.14` — на 3.12/3.13 установка пакета упадёт.
- `invest-games: command not found` — активируйте `.venv` или вызовите `python -m invest_games.cli`.
- Ключ не виден — проверьте, что `.env` лежит рядом с `pyproject.toml` и команда запущена из этого каталога.
- Порт 8000 занят — остановите старый процесс или поднимите uvicorn на другом порту.
- Сеть/RouterAI — в консоли и вебе будет ошибка, Терпение не спишется; повторите тот же ход.
